# LinkUp - Real-Time Video Calling Platform

LinkUp is a modern real-time video calling platform designed to provide a smooth and interactive online meeting experience. It enables users to communicate through video and audio while also providing features such as real-time chat, screen sharing, reactions, hand raising, and host-controlled participant access.

The project is built with React.js on the frontend and Node.js, Express.js, Socket.IO, MongoDB, and WebRTC on the backend.

## ✨ Features

- Real-time video calling
- Real-time audio communication
- Screen sharing
- Real-time chat
- Host and participant management
- Join request approval system
- Host transfer when the current host leaves
- Raise hand functionality
- Emoji reactions
- Participant list
- Camera and microphone controls
- Meeting-based room system
- Responsive meeting interface
- JWT-based authentication
- WebRTC peer-to-peer communication
- TURN server support for reliable connectivity
